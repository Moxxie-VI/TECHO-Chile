A) SISTEMA DE RECORDATORIO 120 DÍAS DS 49 ⚠️ (CRÍTICO)
   Ubicación: core/models.py y core/views.py
   
   QUÉ HACER:
   1. Agregar campo fecha_recepcion al modelo Proyecto:
      fecha_recepcion = models.DateField(null=True, blank=True)
   
   2. Agregar método al modelo Proyecto:
      def dias_transcurridos_postventa(self):
          if not self.fecha_recepcion:
              return None
          from datetime import date
          dias = (date.today() - self.fecha_recepcion).days
          return dias
      
      def dias_restantes_ds49(self):
          if not self.fecha_recepcion:
              return None
          dias_trans = self.dias_transcurridos_postventa()
          return 120 - dias_trans
      
      def esta_cerca_vencimiento(self):
          dias_rest = self.dias_restantes_ds49()
          if dias_rest is None:
              return False
          return dias_rest <= 15  # Alertar 15 días antes
      
      def ha_vencido_ds49(self):
          dias_rest = self.dias_restantes_ds49()
          if dias_rest is None:
              return False
          return dias_rest < 0
   
   3. Crear migración:
      python manage.py makemigrations
      python manage.py migrate
   
   4. Agregar alertas en dashboard_admin.html:
      {% for proyecto in proyectos %}
          {% if proyecto.ha_vencido_ds49 %}
              <div class="alert alert-danger">
                  ⚠️ Proyecto {{ proyecto.codigo }} ha excedido los 120 días
              </div>
          {% elif proyecto.esta_cerca_vencimiento %}
              <div class="alert alert-warning">
                  ⏰ Proyecto {{ proyecto.codigo }} vence en 
                  {{ proyecto.dias_restantes_ds49 }} días
              </div>
          {% endif %}
      {% endfor %}
