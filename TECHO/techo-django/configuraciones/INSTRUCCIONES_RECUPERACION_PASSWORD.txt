PASO 1: Crear las migraciones de base de datos
-----------------------------------------------
cd techo-django
python manage.py makemigrations accounts

Deberías ver algo como:
  Migrations for 'accounts':
    accounts/migrations/0001_initial.py
      - Create model TokenRecuperacion


PASO 2: Aplicar las migraciones
--------------------------------
python manage.py migrate

Deberías ver:
  Running migrations:
    Applying accounts.0001_initial... OK


PASO 3: Configurar el envío de emails (OPCIONAL)
------------------------------------------------
Si quieres que se envíen correos REALES:
  
  1. Lee el archivo: CONFIGURACION_EMAIL.txt
  2. Sigue las instrucciones para configurar Gmail
  3. Agrega las variables al archivo .env

Si NO configuras email:
  - Los "correos" se imprimirán en la consola/terminal
  - Sirve para hacer pruebas sin necesidad de configurar nada


PASO 4: Probar el sistema
--------------------------
1. Inicia el servidor:
   python manage.py runserver

2. Ve a: http://localhost:8000/login/

3. Click en "¿Olvidaste tu contraseña?"

4. Ingresa un correo de un usuario existente

5. Si configuraste email:
   ✅ Recibirás un correo con el código
   
   Si NO configuraste email:
   ✅ Verás el código en la terminal

✅ Modelo TokenRecuperacion en la base de datos
   - Almacena códigos únicos de 6 caracteres
   - Códigos válidos por 15 minutos
   - Control de uso (un código solo se usa una vez)

✅ Vista de solicitud (recuperar-password/)
   - Usuario ingresa su correo
   - Sistema genera código único (ej: A3K9M2)
   - Envía email con el código
   - Seguridad: no revela si el correo existe

✅ Vista de verificación (recuperar-password/verificar/)
   - Usuario ingresa el código recibido
   - Ingresa nueva contraseña (con confirmación)
   - Validaciones de seguridad
   - Verificación en tiempo real de contraseñas

✅ Templates HTML profesionales
   - Diseño moderno y responsive
   - Instrucciones claras
   - Retroalimentación visual
   - Botón para mostrar/ocultar contraseñas

✅ Link en el login
   - "¿Olvidaste tu contraseña?" visible y accesible

✅ Panel de administración
   - Ver todos los tokens generados
   - Filtrar por usado/no usado
   - Ver si están vigentes

✅ Configuración de email
   - Soporte para Gmail, Outlook, Yahoo, SendGrid
   - Modo consola para desarrollo sin configuración

P: ¿Puedo cambiar la duración del código?
R: Sí, en accounts/models.py, línea 32, cambia 900 (15 min) 
   por el valor en segundos que desees.

P: ¿Puedo cambiar el largo del código?
R: Sí, en accounts/models.py, línea 42, cambia range(6) 
   por el largo que prefieras.

P: ¿El código puede tener solo números?
R: Sí, en models.py línea 40, cambia:
   caracteres = string.ascii_uppercase + string.digits
   por:
   caracteres = string.digits

P: ¿Puedo personalizar el email?
R: Sí, edita accounts/views.py línea 249-273.

P: ¿Funciona con usuarios que no tienen email?
R: Solo funciona con usuarios cuyo username sea su email.
