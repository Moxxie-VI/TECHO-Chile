Stack oficial del proyecto
Frontend (web responsiva + PWA)
•	TypeScript: JavaScript tipado; menos errores y código más claro.
•	Next.js: Framework React con SSR/SSG; rutas ordenadas, performance y SEO.
•	React: Librería de componentes para construir la UI.
•	HTML5 + CSS3: Base de todas las vistas; el CSS lo manejamos principalmente con Tailwind.
•	Tailwind CSS + Headless UI: Estilos rápidos y consistentes; componentes accesibles (modales, menús, etc.).
•	TanStack Query: Manejo de data del servidor (caché, reintentos, sincronización).
•	React Hook Form + Zod: Formularios y validaciones estrictas (checklists, actas).
•	Workbox (PWA): Funciona offline en terreno; cola de sincronización.
•	Uppy: Subida de evidencias (fotos, audio, video) con reintentos y “chunking”.

Backend (API, lógica, reportes)
•	Python + FastAPI: API rápida, con tipos y documentación OpenAPI automática.
•	Autenticación JWT (RBAC): Tokens con roles (TECHO, Constructora, Beneficiario, SERVIU) y permisos por módulo.
•	Celery + Redis: Tareas en segundo plano (generar PDFs, crear thumbnails, procesar multimedia).
•	Playwright (HTML→PDF): Reportes oficiales (Acta de Recepción, Ficha Postventa, Cierre) con logos y firmas.
•	Pillow + FFmpeg: Optimiza imágenes y genera miniaturas de audio/video.

Datos y almacenamiento
•	PostgreSQL: Base de datos principal (integridad, trazabilidad, auditoría).
•	PostGIS (opcional): Si registramos coordenadas/recorridos en terreno.
•	MinIO (local) / S3 (nube): Almacenamiento de evidencias con URLs prefirmadas (seguro y escalable).

Seguridad y cumplimiento (DS49)
•	TLS (HTTPS) + buenas prácticas OWASP: Cifrado y mitigación de riesgos comunes.
•	Auditoría inmutable: Bitácora de acciones, hash SHA-256 de PDFs/evidencias y sello de tiempo.
•	Política de datos: Enmascaramiento de PII y retención acorde a DS49.

Infraestructura / DevOps (local y demo)
•	Docker Compose: Levanta todo el ecosistema (web, api, db, redis, minio, mailpit, proxy).
•	Mailpit: Pruebas de correo sin enviar mails reales (notificaciones).
•	Traefik: Proxy/reverse proxy y TLS local si hace falta.
•	ngrok o Cloudflare Tunnel: Mostrar la demo del backend local de forma segura
.
Desarrollo y colaboración
